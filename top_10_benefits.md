# Top 10 Benefits of Tundra Frontmatter Wrangler

1. **Structured 6-Step Guided Workflow**
   - **Benefit:** Makes bulk metadata updates safe and predictable through a clear: Select > Inspect > Configure > Preview > Apply > Review flow.
   - **Example:** Follow the wizard to rename a property across 200 notes without worrying about syntax corruption.

2. **Safe Top-Level Property Renaming with Merge Strategies**
   - **Benefit:** Rename frontmatter keys across hundreds of files with conflict resolution rules.
   - **Example:** Rename `published_date` to `date`, choosing whether to overwrite, keep existing, or merge array values.

3. **Bulk Tag Management & Standardization**
   - **Benefit:** Add, remove, replace, or normalize tags across notes without breaking frontmatter formatting.
   - **Example:** Replace `#status/wip` with `#status/in-progress` across an entire folder while deduplicating existing tags.

4. **Tag Syntax Normalization Rules**
   - **Benefit:** Enforce consistent tag casing and separator conventions vault-wide.
   - **Example:** Automatically standardize mixed tags to `lowercase` and convert spaces to hyphens (`project plan` -> `project-plan`).

5. **Frontmatter Schema Reordering**
   - **Benefit:** Organize frontmatter properties into an ordered, consistent visual hierarchy.
   - **Example:** Standardize all notes so `title` is always first, followed by `date`, `tags`, and `status`.

6. **Granular Per-Note Diff Previews**
   - **Benefit:** Review exact YAML changes file by file and toggle specific notes on or off before applying.
   - **Example:** Inspect a side-by-side YAML diff and uncheck 2 special notes you wish to leave unchanged.

7. **Stale-Preview & Conflict Protection**
   - **Benefit:** Refuses to write changes if a note was edited externally while the preview was open.
   - **Example:** Prevents overwriting changes if Obsidian Sync or another device modified the file mid-review.

8. **One-Click Batch Rollback**
   - **Benefit:** Safely revert the most recent batch operation back to the exact previous frontmatter state.
   - **Example:** Click *Rollback last batch* to instantly restore previous YAML keys if a property name was mistyped.

9. **Isolation of Malformed Frontmatter**
   - **Benefit:** Identifies syntax errors and skips corrupted frontmatter rather than silently damaging it.
   - **Example:** Flags a note with broken indentation in YAML so you can fix it manually without risking data loss.

10. **Generous Daily Free Allowance**
    - **Benefit:** Perform daily organizational updates without purchasing credits.
    - **Example:** Apply 3 multi-note frontmatter update batches every calendar day at zero cost.
